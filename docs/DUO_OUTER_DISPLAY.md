# Duo 外屏首页布局

在「我的音乐 → Duo 外屏布局」开启。普通布局默认不变，开关保存在本机。该开关用于目前 SDK 下的手动适配验证，不代表已经接入 Duo 的自动外屏检测。

- 竖向首页保留四列方形封面，相邻列错开半张封面。
- 右侧预留 60pt 内容控制区域；队列、设置使用 50pt 宽、半透明玫红色竖向胶囊，两个按钮点击区域均为 44×44pt。
- 队列入口打开真实播放队列，选择歌曲沿用原来的保序播放方法；播放列表切换保留在弹层内。
- 底部播放条上限 260pt，在扣除右侧控制区后的内容区域居中。
- 时间、摄像头、网络状态均由系统负责；不在 App 内仿绘。
- 减少透明度辅助功能开启时改为实色填充。

## 验证

2026-09-17：使用 Xcode 26.6 / iOS 26.5 SDK 编译通过。产物在 iOS 27.0 iPad 模拟器启动，人工验证右侧队列弹层打开/关闭、设置入口以及设置开关显示。自动 UI 测试受 CoreSimulator 启动服务错误影响，未完成；不能标记通过。

实际 Duo 外屏系统安全区、侧边原生工具栏与自动姿态切换仍需要支持该设备的 SDK / 模拟器验收。目前不是实际 Duo 设备截图或真机验证。

自动化入口：Debug 启动参数 `--duo-home`。对应测试 `DuoHomeUITests` 验证队列、设置和退出外屏布局。
