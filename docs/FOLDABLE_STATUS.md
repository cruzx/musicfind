# 折叠屏开发分支

分支：`feature/foldable-support`

状态：开发稿保存，等待支持折叠屏的模拟器后继续测试。当前不合并回主分支，也不视为完成折叠屏适配验收。

## 已实现

- 手动悬停入口：上方横屏播放器、下方歌曲封面队列。
- 手动外屏布局开关：四列错位封面、短播放条、右下角玫红队列/设置胶囊。
- 复用当前播放、暂停、保序切歌逻辑。

## 后续设备验收

- 支持该设备的 SDK 与模拟器到位后，接入系统折叠区域和姿态 API。
- 检查外屏系统侧栏、安全区域、摄像头/灵动岛避让。
- 检查展开、合起、横向悬停、竖向书本姿态及窗口尺寸变化。
- 竖向书本姿态的左播放器/右封面墙仍需正式实现并验收。
- 验证切换姿态时播放状态、队列、滚动位置连续性。
- 检查最后一排可达性、较大字体、减少透明度、VoiceOver。
- 重跑布局与 UI 测试，再进行真机音乐服务测试。

此前普通模拟器的构建和交互结果见 `FLEX_PLAYER.md`、`DUO_OUTER_DISPLAY.md`，不等同于折叠屏专项测试通过。
