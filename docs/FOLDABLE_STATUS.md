# 折叠屏开发分支

分支：`feature/foldable-support`。独立于主分支。

## 2026-09-28 实现

- iOS 27.1 使用 `GeometryProxy.reservedRegions(kind: .division)` 的真实有效分隔区自动布局，低版本保留手动悬停入口。
- 横向分隔：上方横屏播放器，下方方形专辑队列。每行约 5.5 张，交替行从两端展示，初始相差半张；每行可左右滚动，整个队列可上下滚动。
- 竖向分隔：左侧竖屏播放器，右侧四列半张错位的封面墙与歌曲标题。
- 播放条最大 260pt，按所在分区宽度缩小。分隔区域不放控件。
- 正式首页在折叠时自动进入、合起/完全展开时回到原首页；检测折叠后记住外屏布局开关。手动退出本次折叠界面后不会立即再次弹出。
- 播放和队列继续使用同一 MusicConnectionManager。界面切换不主动暂停或重新建立播放队列。
- 自动折叠覆盖层显示时，底层首页不可点击且不暴露给辅助功能。

## 验证

Xcode 27.1 / iOS 27.1 iPhone Duo 模拟器：编译通过，8 项布局测试通过，空队列退出与选歌/暂停/末尾滚动/退出两项 UI 回归通过。首次 UI 回归的立即状态断言失败后，改为等待状态更新并固定初始方向，独立重跑通过。人工查看书本/横向悬停，验证测试曲目切歌、暂停后旋转，歌曲 ID 和暂停状态保留。正式入口确认折叠自动显示播放器，合起返回首页。

截图 `duo-validation/book.png`、`tabletop.png` 使用本地测试封面，不是实际音乐库。当前模拟器未登录音乐服务，正式队列为空的提示已检查；真实音乐续播需有曲库的设备验证。

当前依然复用原有自绘队列/设置胶囊，并未替换成系统原生侧边工具栏。该分支未合并主分支。
